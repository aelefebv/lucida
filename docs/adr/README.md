# Architecture Decision Records (ADR)

Use ADRs for cross-cutting or hard-to-reverse design decisions.

## ADR Format

1. Status (`proposed`, `accepted`, `superseded`, `deprecated`).
2. Context.
3. Decision.
4. Consequences.
5. Alternatives considered.

## Naming

`ADR-XXXX-short-title.md`

Example:

- `ADR-0001-context-governance.md`
