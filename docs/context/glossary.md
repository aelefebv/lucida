# Context Glossary

- **Spec**: High-level product intent (`SPEC.md`).
- **Sub-spec**: Step-level implementation-oriented roadmap spec (`specs/roadmap/step-*.md`).
- **Protocol artifact**: Machine-readable command contract in `protocol/`.
- **Traceability row**: One step mapping to status, implementation paths, test paths, and protocol artifacts.
- **Context index**: Catalog of context artifacts and their maintenance trigger.
- **Guidance-first**: Strong SHOULD policy with explicit assumptions when blocked, not hard-fail by default.
