# Support

Use GitHub issues for reproducible bugs and focused feature requests. Include
the Lucida version or image digest, browser/client version, deployment shape,
dataset format and backend (without private URLs), expected behavior, actual
behavior, logs with credentials removed, and the smallest safe reproduction.
The project is maintained on a best-effort basis and does not promise response
or resolution times.

Check [COMPATIBILITY.md](COMPATIBILITY.md) before filing an environment or data
format problem, and use the repository wiki for architecture and operational
guidance. Questions about a private deployment's cloud, ingress, identity, or
storage configuration may need support from that platform's operator.

Security reports do not belong in public issues. Follow
[SECURITY.md](SECURITY.md) for the private reporting path and response
expectations.
