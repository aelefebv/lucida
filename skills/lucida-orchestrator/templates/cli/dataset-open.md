# dataset.open

## Command
```bash
lucida dataset open --uri <dataset_uri> --dataset-id <dataset_id> --session-id <session_id> --json
```

## Required Inputs
- `uri`

## Expected Output Fields
- `dataset_summary.dataset_id`
- `dataset_summary.multiscales`

## Common Failure Codes
- `invalid_request`
- `dataset_not_found`
