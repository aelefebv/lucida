# Inputs — Read-Only Source Material

Source material the wiki is compiled *from*: RFCs, design docs, PR descriptions, meeting notes, exported tickets, transcripts. Any text-format reference document can be dropped here.

## Conventions

- **Read-only.** The compile pass reads from this directory but never modifies files in it.
- Formats are flexible (`.md`, `.txt`, `.pdf`, `.html`).
- Name files for their content (e.g. `prd-378-worker-protocol.md`, `rfc-import-pipeline.md`).
- When an input is folded into an article, the article cites it with a `<!-- compiled from inputs/{filename} -->` comment.
