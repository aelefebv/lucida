- **Chunk-only coarse/detail residency (PRD #672):** Default fallback moved from proxy assets to explicit `detail` and `coarse` chunk tiers. Detail defaults to the finest selectable source level and only changes when the user explicitly picks a lower source LOD; generated levels are excluded from detail selection. Coarse uses a source coarse level when present or a server-generated derived pyramid level served through the normal chunk path. CPU/GPU residency keep detail and coarse in separate buckets/pools with elastic borrowing only when one lane has no demand. Generated coarse readiness is surfaced through runtime availability deltas and `GeneratedChunkStatus`; pending chunks do not enter failure tracking. Legacy proxy fallback is opt-in behind `--legacy-proxy-enabled`. ADRs [[decisions/0039-chunk-only-coarse-detail-residency]], [[decisions/0040-generated-coarse-as-derived-pyramid-levels]], [[decisions/0041-clean-two-source-chunk-tier-renderer]].
