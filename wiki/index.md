# Lucida Wiki — Index

This wiki records **why** Lucida is shaped the way it is. It deliberately does *not*
describe what the code currently does — the code is the only trustworthy source for
that. Read `intention.md` at the repo root for the north-star, then come here for the
reasoning behind specific choices.

See [CLAUDE.md — Lucida Repo Wiki](CLAUDE.md) for conventions and maintenance rules.

## Categories

- [Principles](principles/index.md) — stable claims about what each part of the product optimizes for
- [Decisions](decisions/index.md) — numbered ADRs (`0001-…` onward) recording architectural choices and their rationale

## Quick paths

- "What is this part of the product trying to optimize for?" → [Principles](principles/index.md)
- "Why was X done that way?" → [Decisions](decisions/index.md) (and the principles they cite)
- "What does the code do today?" → read the code. Nothing here is kept in sync with it.
